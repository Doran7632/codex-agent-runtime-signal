# codex-agent-runtime-signal 1.6.0

- Codex CLI 请求提权或明确要求审批时，会显示红色权限气泡。普通输入请求仍显示等待输入状态。
- 打开菜单时会刷新会话列表，改善多个 IDE 同时运行 Codex 时的识别，并区分 Codex Desktop 与 VS Code。
- Claude Code 会话优先展示自定义名称，没有自定义名称时使用首条提示词。

本版适用于 Apple 芯片 Mac，最低系统版本为 macOS 14。下载 `CodexAgentRuntimeSignal.dmg`，打开后将 App 拖入「应用程序」。ZIP 另含命令行工具、脚本和源码。

本版使用 ad-hoc 签名，未经 Apple 公证，请通过 GitHub Release 手动更新。将校验文件与 DMG、ZIP 放在同一目录，运行 `shasum -a 256 -c CodexAgentRuntimeSignal-SHA256SUMS.txt` 可核对下载文件。
